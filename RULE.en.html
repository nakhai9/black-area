0. Working rules for AI

  • TypeScript strict. After editing always run npm run typecheck, leave no errors.
  • All gameplay numbers (cost, HP, speed, range, limits) go in src/constants.ts, with JSDoc. Do not hard-code numbers in systems.
  • Differences between factions → src/factions/<phe>.ts (stats multipliers, flags oilCartel / peaceful / leasesOil), avoid branching if (faction === ...) in logic.
  • src/types/index.ts contains only types.
  • Keep the surrounding code style: short JSDoc, English, meaningful names.
  • Do not change a unit's on-screen display name when only changing its sprite/internals.
  • Ask the user before every git push.
  • Version: GAME_VERSION (x.y.z) in src/constants.ts, right below DEMO_MODE. After every change: bug fix / number tweak → bump z; new content / new rule → bump y, reset z to 0; major change that makes old save files unloadable → bump x, reset y and z to 0. Write the same number into the title of RULE.html and README.md.
  • Two coordinate systems: world px (logic, square CELL_SIZE cells) and iso screen (2:1 diamond, ISO_X = 0.5, ISO_Y = 0.25, see core/IsoView.ts).

3. World

  • Map = real Earth (4096×2048 texture, WORLD_SCALE = 5.5 world px/texel). Atlantic narrowed (ATLANTIC_SQUEEZE): the longitude band -34° → -17° (between the tip of Brazil and Senegal) keeps only 40% of its width when the texture is loaded, so the Americas are about 10° of longitude closer to Europe – Africa; the coastlines of Brazil, West Africa and Europe keep their shape, Iceland and eastern Greenland get narrower. Eastern Pacific narrowed (PACIFIC_SQUEEZE): the longitude band -152° → -125° (between Hawaii and the Americas) keeps only 35% of its width at latitudes -45° → 40° (blending over 7° outside that range), so Hawaii and the whole Pacific to the west shift about 17.5° of longitude closer to the Americas; Alaska, Vancouver Island and Antarctica are unchanged. This band is almost entirely sea (only a few small Polynesian islands like Tahiti, Marquesas get narrower); the empty space at the western map edge is sea. Greenland restored to its true area: each row of Greenland land is narrowed by cos(latitude) around meridian -42° (the equirectangular projection stretches polar regions by 1/cos(latitude)), the excess land becomes sea; the north–south extent is unchanged. Only Greenland is adjusted, Canada / Russia / Antarctica still follow the old projection. Remaining texture width EARTH_TEX_WIDTH ≈ 3980 texels; every longitude ↔ coordinate conversion goes through map/Geo.ts (lonToFrac / fracToLon). MAP_SEED = 20261005.
  • Unit cell: a 1×1 grid cell, the common unit of measure for the whole system (pathing, building placement, footprint, flags, distances in cells); size CELL_SIZE = 7 world px. In DEMO mode the whole unit-cell grid (both land and sea) is drawn on the map. RA2-style isometric display, camera does not rotate.
  • Tactical zoom ZOOM_MIN 3 – ZOOM_MAX 9 (step 1.12, FOCUS_ZOOM 8); the overview is on the sidebar radar.
  • Capitals at real coordinates (CAPITAL_LOCATIONS): Washington D.C., Moscow, Beijing, Paris, Riyadh (Islamic). Global Monitoring Center (neutral, WorldBank) in Zürich.
  • No building casts a shadow on the ground.
  • Compass in the bottom-left corner of the screen (above the Zoom/FPS bar): Font-GIS compass rose icon (Jean-Marc Viglino, CC-BY license, credited in index.html), yellow, lying on the ground in the map's 2:1 isometric projection so directions match the game: N (north) points up-right, E (east) down-right, S (south) down-left, W (west) up-left. Not clickable.
  • Capitals not on the coast: when the map is built, each capital (of the 5 factions and of the contested nations) is moved to the spot closest to its real location (within CAPITAL_INLAND_SEARCH = 20 cells) where every cell around it within CAPITAL_SEA_CLEARANCE = 4 cells is land (more than 3 cells from the sea); if none is found the old placement is kept.
  • Contested nations (CONTESTED_NATIONS, entity NationCapital, type nationCapital): North Korea (Pyongyang), South Korea (Seoul), Japan (Tokyo), Australia (Canberra), Brazil (Brasília), UK (London, 10 Downing Street — has left the EU so Great Britain no longer belongs to Europe's territory), Canada (Ottawa, Parliament Hill — Canadian land is split from USA territory; USA keeps the contiguous US + Alaska), Cuba (Havana, El Capitolio — Cuba is not part of USA territory). Independent capitals, initially neutral; cannot be destroyed, only captured by an engineer (from neutral or from the faction holding it). The holding faction receives NATION_PRESENCE_FEE 1200 TB every NATION_PRESENCE_PERIOD 120s (military presence fee, via TaxSystem, debt paid first) and may build its own buildings next to that capital (like an Allied Building). Does not count as the faction's own capital when checking defeat. A captured capital still counts as an ally of the holder: shown in the Allies tab, when hovering that row and when hovering the capital on the map with the name "nation + faction" (e.g. "South Korea + Russia", the + marks cooperation; in the Allies tab row it shows the capturing faction's logo + lucide icon Handshake + the captured nation's flag), not counted toward the MAX_ALLIES limit. AI (from 90s, when home is quiet) sends 1 engineer to capture the nearest capital it doesn't hold (across sea: carried by transport plane), and keeps NATION_GARRISON 6 soldiers/vehicles garrisoned at each capital it holds (within NATION_GARRISON_CELLS 10 cells).
  • Antarctic oil (ANTARCTIC_OIL_SITES, OilDerrick.antarctic): 5 ownerless oil derricks spread evenly across Antarctica. Pump under the usual oil rules for the holding faction; cannot be destroyed; engineers of any faction can capture them (from ownerless or from another faction), even if the holding faction leases oil: Antarctic derricks are never leased, engineers always capture. No building of any kind may be built on Antarctica (every cell from ANTARCTIC_ROW = 60°S southward, PlacementSystem.check → reason antarctica), applies to both player and AI. AI treats them as contested targets: sends engineers by transport plane to capture them and leaves garrison troops to defend them (like contested capitals).
  • AI transport planes (AISystem.safeDrop): when carrying troops / engineers far away, choose a landing point within SAFE_DROP_CELLS 24 cells of the target that is least covered by other factions' soldiers / vehicles / bunkers.
  • Radar (minimap): neutral / unowned buildings are drawn as triangles; faction buildings are drawn as round dots.
  • Forest slows ground units ×0.78. Water: only special soldiers can swim (SWIM_SPEED_FACTOR 0.6); vehicles do not enter water.
  • Mountain ranges (MOUNTAIN_RANGES, WorldGenerator.markMountains, v1.112.0): Himalaya (from Nanga Parbat 8,126 m in the west through Nanda Devi, Dhaulagiri, Everest, Kangchenjunga to Namcha Barwa 7,782 m in the east, v1.115.0), Andes, Rocky, Alps, Altai (blocking Russia – China, running straight west to east along ~49°N, v1.114.0), Ural (blocking European Russia – Siberia), Caucasus (blocking South Russia – West Asia), Pamir + Karakoram (blocking Middle East / South Asia – China) — following real ridge lines. The Turkish Straits are water already on the map. Vesi (fictional, v1.116.0): a straight range from 39.87°N 75.44°E (Pamir) to 47.68°N 82.16°E (western end of Altai), v1.117.0, blocking the route from Russia down to China and vice versa; no passes — ground troops must detour around one of the two ends of the range (pathfinding retries with a large budget DETOUR_EXPANSIONS when the first search does not reach the goal). Where two ranges join, the slopes of the later range do not overwrite the ridge / passes of the earlier range (no gaps). Each range is ~MOUNTAIN_HALF_WIDTH_CELLS = 6 cells wide on each side (wavy edges): the ridge in the middle (MOUNTAIN_CREST_CELLS 1.3 cells, peaks as high as real NASA elevation, snowy, impassable) and the slopes on both sides (high ground: walkable, buildable — defensive positions). No outer cliff walls. Passes: MOUNTAIN_PASSES = 3 passes per range spaced evenly, 3 cells wide, cutting through the ridge — the only way to cross the mountains; slow going (infantry ×0.6, vehicles ×0.45). High-ground advantage (ground units on slopes): range ×1.2, damage to units below ×1.25; fire from units below deals only ×0.75. Aircraft are unaffected. Applies to AI too. Hovering the mouse over a mountain area (not over a unit / building) shows the range name right above the cursor (Game.mountainTip, Renderer.drawMountainTip, v1.113.0).

War / peace cycle (WAR_SECONDS, PEACE_SECONDS, Game.updateWarCycle)

  • Repeats forever: 10 minutes of war (fighting, capturing each other) then 2.5 minutes of peace (building up your own faction). The match starts with war.
  • Peace: no faction can attack another (isHostile = false), all attack orders / locked targets / Crazy Soldier bombs are cancelled, advancing troops stop in place, no capturing other factions' buildings (neutral buildings can still be captured).
  • Ceasefire zone (v1.118.0, TRUCE_ZONE_CELLS = 5, Game.updateViolators): during the 2.5 minutes of peace, after the first TRUCE_GRACE_SECONDS = 15 s to withdraw, every soldier / vehicle / aircraft / flying helicopter within 5 cells of the edge of another faction's building is a ceasefire violator: every other faction may attack it, and it may not fire back. A red "Ceasefire violation" label shows above it; the player is warned (at most once every 10 s). Exceptions: engineers on their way to lease an oil derrick, aircraft parked / taxiing / helicopters landing.
  • AI during peace only develops economy, base, army; launches no attacks. AI keeps every unit more than 5 + 2 cells from other factions' buildings (including the destination point): any unit near or about to enter the zone retreats to the capital; troop trucks near the zone unload their troops (AISystem.keepCeasefire).
  • The sidebar shows the current phase and time remaining (War / Peace m:ss).

4. Economy (oil)

  • Currency TB. Every faction starts with STARTING_CREDITS = 0 TB and STARTING_OIL = 20 barrels.
  • Buildings/troops are paid for gradually while in progress; when money runs out progress stalls. Building: every BUILD_STEP_SECONDS 4 s advances 20%.
  • Losing your own capital (capitalLost) → can no longer buy anything (including oil for the power grid).

Oil derricks (OilDerrick, pre-placed by Game.placeOilRows)

  • Number of derricks OIL_DERRICK_COUNT: 2/faction, Islamic 3. At most OIL_ROW_MAX = 4 derricks per row.
  • Location: safe land inside own territory (prefer depth ≥ 6 cells, relaxed gradually), far from own capital and enemy capitals; at least OIL_FIELD_SPACING = 40 cells from other factions' derricks (20 as a last resort). Only when there's no room inside the country may they go outside.
  • OIL_SITES: Islamic field is mandatory at Abu Dhabi (UAE, lon 54.0, lat 23.3, inside territory, radius 16 → 24 → 32 cells); Russian field mandatory in Western Siberia (Samotlor, lon 76.6, lat 61.1), radius 16 → 24 → 32 cells, always inside Russian territory; Chinese field mandatory in Xinjiang (Karamay, lon 84.9, lat 45.6), same radius rule, always inside Chinese territory; US field mandatory in Texas (Permian Basin, near Midland, lon -102.1, lat 31.9), same radius rule, always inside US territory; European field mandatory on the Northern European mainland (central Sweden, lon 15.0, lat 61.2: the widest land area far from sea and lakes), same radius rule, always inside European territory.
  • Output OIL_DERRICK_OUTPUT = 0.08 barrels/s per derrick while pumping. Cycle: pump OIL_MINE_SECONDS 180 s, rest OIL_REST_SECONDS 60 s; derricks are 40 s out of phase.
  • Each field has 1 bankManaged derrick (managed by the Center): still belongs to the faction, cannot be destroyed / captured.
  • Derricks of the leasesOil faction (Islamic) currently cannot be destroyed or captured.
  • Grace period: the player's derricks cannot be attacked until enemy factions have launched DERRICK_GRACE_ATTACKS = 5 attack waves on the player's buildings (a new wave = attacking again after ≥ DERRICK_GRACE_GAP = 30 s of silence).
  • O key: cycle through derricks.

Oil price (systems/OilMarket.ts)

  • Shared price, starting at OIL_PRICE_START 900, clamped to OIL_PRICE_MIN 360 – OIL_PRICE_MAX 2100 TB/barrel; re-evaluated every OIL_PRICE_INTERVAL 10 s, each time moving OIL_PRICE_EASE 35% of the distance to the target price.
  • balancePrice = 900 × wealth × flow × cartelFactor:
  • flow = ((OIL_FLOW_REF 3 + bought) / (3 + sold)) ^ 0.5 — sold = barrels factions sold to the Center, bought = barrels the Center was forced to sell to the power grid; both fade over OIL_FLOW_MEMORY 90 s. Selling a lot → cheaper; grid buying a lot → pricier.
  • wealth = ((15000 + tài sản ròng TB/phe) / 15000) ^ 0.3 (OIL_WEALTH_*; net worth = money + collateral − debt, only factions not yet eliminated).
  • cartelFactor = OIL_POLICIES[policy].price while a cartel faction remains.
  • Target = balancePrice × (1 + mood); seeded random mood, ±OIL_MOOD_MAX 12%, steps of ±4%, pulled back toward 0 by 15% each time.
  • The price chart keeps the last 30 evaluations (5 minutes).

Selling oil

  • Selling = offering the whole stock minus OIL_RESERVE = 1.0 barrel always kept; need ≥ 0.5 barrels to offer.
  • Amount the Center buys = kho × WB_MAX_SHARE (25%) × (1 − 0.6 × giá / OIL_PRICE_MAX).
  • Money = round(thùng × giá) via OilMarket.receive(): debt is paid first, the rest goes to the treasury.
  • Rhythm: OIL_SALE_BURST = 6 times in a row, then wait OIL_SALE_COOLDOWN = 3 s.

Leasing derricks (leasesOil)

  • An Engineer of another faction right-clicks an Islamic derrick → leases it for OIL_LEASE_SECONDS = 180 s. During the lease, the derrick belongs to the leasing faction (changes color, changes owner, oil goes to the lessee's stock, counted separately as leasedOil); still cannot be destroyed / captured. An engineer entering a derrick of another enemy faction (not Islamic) captures it outright: the derrick becomes yours. Applies to both player and AI.
  • When selling, the money from leased oil gives OIL_LEASE_CARTEL_SHARE = 30% to the lessor. On expiry the derrick returns to Islamic.
  • Islamic does not shoot engineers on their way to lease its derricks; other factions still attack that engineer if they meet it on the way.
  • AI-controlled factions (other than Islamic) also lease on their own (AISystem.leaseOil): only when the lease is profitable — 180 s of oil × current price × 70% ≥ LEASE_MIN_RETURN 2 × the price of one engineer; at most AI_LEASES 2 derricks per faction (still within Islamic's OIL_LEASE_MAX 4 limit); only derricks within LEASE_RANGE_CELLS 120 cells of the engineer, nearest first; no leasing while the capital is under attack. Uses an idle engineer (after building repairs are handled); if none, trains one.

Helicopters (heli)

  • Apache (USA, Europe), Ka-52 (Russia, Islamic), Z-10 (China). Only shoot ground vehicles: do not shoot buildings, soldiers, aircraft.
  • Park anywhere on land like vehicles; carry at most HELI_SOLDIERS = 8 soldiers, no vehicles.
  • Helicopter self-defense: when parked and shot by soldiers or ground vehicles/tanks → takes off, locks onto the attacker and fights back (exception: may also shoot that soldier; Vehicle.heliRevenge, ends when the fight is over or a new order is given), after the fight flies back to the exact original spot and lands again (a new order cancels the return). Applies to both player and AI.

Emergency loans (Global Monitoring Center)

  • Only when the treasury is < 1 TB, only when the player presses the button (not automatic). No interest.
  • collateral = oil × giá + RESALE_SHARE (0.5) × (giá xây công trình × tỉ lệ máu + giá gốc xe) (indestructible buildings excluded).
  • credit line = floor(LOAN_TO_VALUE (0.5) × collateral / 100) × 100.
  • Each loan = LOAN_SHARE (25%) of the credit line (≥ LOAN_MIN 1000, not exceeding the line). Added to debt.
  • Debt hits the line → credit frozen until debt ≤ DEBT_RESUME_SHARE (0.5) × line. All income via receive() pays debt first.

Other income

  • Happy City: HAPPY_CITY_TAX 600 TB every HAPPY_CITY_TAX_PERIOD 50 s, each city has its own timer (TaxSystem). More cities mean higher tax: each other city of the faction adds HAPPY_CITY_TAX_BONUS 0.15 × base tax to every city (5 cities: each ×1.6).
  • Mercy bonus: MERCY_BONUS 100 TB for letting a retreating enemy group go without chasing (once / group / faction).

Power (PowerSystem)

  • Each building consumes powerDrain/s. The energy unit is the joule (J), named after physicist James Prescott Joule; power is measured in J/s. A nuclear power plant generates POWER_PLANT_OUTPUT 25 J/s (scaled by HP: a plant at 50% HP only generates 12.5 J/s and stores half) by burning oil: POWER_PER_BARREL 1000 (0.025 barrels/s at full capacity), stores at most POWER_PLANT_STORAGE 300 (new plants start at 0).
  • One plant is enough for 1 set: capital 1 + barracks 1 + hospital 2 + war factory 3 + airfield 4 + tech center 6 + city 8 = 25.
  • Grid drained (consumption > generation, storage empty) → the Center is forced to sell oil at OIL_GRID_MARKUP 1.25 × the list price; out of money → power outage.

Movement and pathfinding (map/PathService.ts)

  • Vehicles only move in the direction of their nose (no sideways sliding): ground vehicles more than ~26° off the next waypoint stop and turn in place before driving; aircraft circle according to their turn radius. Aircraft taxiing on the airfield also turn before taxiing.
  • Move orders for a group: one shared flow field (Dijkstra from the destination) inside an HPA* corridor (16×16-cell clusters connected over land), each unit reads its path from the field; work is split across frames (PATH_BUDGET_MS = 3 ms/frame). Paths for a single unit still use direct A*.
  • Formation (like RA2): ground units ordered to move together line up in rows perpendicular to the direction of travel (front row first, later rows behind), on arrival they all face the same direction — never facing each other.
  • Crossings: when the upcoming path segments (4 cells ahead) of two ground units (soldiers, tanks, trucks, ARVs) cross, the unit that reaches the crossing point first goes first; the other stops just before the crossing point and waits its turn (first come, first served), waiting at most CROSSING_MAX_WAIT = 6 s (Game.yieldAtCrossings). Aircraft do not stop but fly higher to avoid each other.
  • Queuing: units following in the same direction slow down behind the vehicle/soldier in front (Game.queueInCrowds); vehicles blocking the way move aside on their own (giveWay).
  • Factory exit (War Factory): vehicles only come out when the door cell is clear — if blocked, production halts at "EXIT BLOCKED" (your own vehicles blocking the door are automatically sent to a parking spot). After exiting, vehicles look for a parking spot around the rally point PARKING_RALLY_CELLS = 3 cells from the door (spiral scan), never parking on the door's exit lane.

  • Queued orders (BuildLimit): BUILD_LIMIT_SOLDIERS 15, BUILD_LIMIT_VEHICLES 10.
  • Parallel production: every order in each tab runs independently and simultaneously. Buildings (Build / Defense tabs): each building type has its own order slot (ConstructionSystem.slot(player, id)), built simultaneously, each waits to be placed separately when finished. Soldiers / vehicles: every order in the queue is worked on simultaneously, each order pays separately (paidEach); when TB is short, older orders are paid first.   • No troop caps: MAX_SOLDIERS, MAX_GROUND_VEHICLES, MAX_TRANSPORTS = unlimited (AI has no truck cap either). Only limited by money, queues (BUILD_LIMIT_*) and aircraft parking at Airfields. Helicopters take no parking slot: not counted toward Airfield parking, they land anywhere on the ground.
  • Landing: select aircraft then click your own airfield (with free parking) → flies in from the nearer runway end (either end works, AircraftSystem.land); only one aircraft uses the runway at a time, others wait above the approach point. Aircraft returning on their own also pick the nearer end.
  • Target lock (explicit attack order) attacks only that target: locking an airfield → only the airfield takes damage, aircraft parked on it are not hit; locking an aircraft / vehicle / soldier on the airfield → only that target (plus a bomber's cluster bombs on ground units around it), the airfield takes no damage. The locked target is a transport aircraft. Airfield destroyed: aircraft parked on it move to another of the faction's airfields; if the faction has no airfield left, aircraft parked on the airfield are destroyed (aircraft in flight crash as before).
  • Switching airfields: select aircraft (flying or parked at another airfield) then click another of the faction's airfields with free parking → the aircraft fly there, land and change their home airfield to the new one (parked aircraft take off first, following the takeoff rules). Airfield full: reports "No free parking spot".
  • Out of parking: an aircraft returning when every airfield of the faction is full crashes immediately — it may not circle waiting for a new airfield to be built. Home airfield destroyed while the remaining airfields are all full: the aircraft crashes immediately (a full airfield is not adopted as home) (applies to both player and AI).
  • Takeoff: queued in the order commanded (first to taxi, first to fly). If a runway end is congested (an aircraft is already waiting there, or a landing aircraft is taxiing toward it), taxi to the other end and take off in the opposite direction; still only one aircraft uses the runway at a time.
  • Low power: the airfield does not allow takeoff (even landing aircraft given a new order must touch down, park and wait for power), but still allows landing.
  • Clicking (move / attack-move) on your own N×M airfield or within the (N+2)×(M+2) area around it (AIRFIELD_CLICK_MARGIN = 2 cells on each side): parked aircraft do not take off, flying aircraft land at that airfield. Save / load

Save file format (durable across all versions)

  • JSON file: format ("black-area-save"), version (the format version = SAVE_VERSION), gameVersion (the game build that wrote it, for reference only), savedAt, faction, nextEntityId, players[], entities[] ({cls, data}), systems{}, game{}, camera. References: {$e:id} entity, {$p:id} player, {$o:id} shop item, {$m} Map, {$s} Set, {$rng}, {$n} special number.
  • Loading never trusts the file to be complete: every entity, system, player and child object starts from the current game build's default values, then the saved values are layered on top (mergeDefaults, recursive). State maps (e.g. per-nation AI state) take defaults from the entry with the same key in the new game. So adding new soldiers / buildings / vehicles / rules / fields needs no changes for old saves — new fields get their defaults automatically.
  • Things removed from the game (entity types, vehicle types, shop items) are skipped and their orders refunded; the shop catalog always comes from code (RULE_FIELDS). Unknown fields in a save cause no errors.
  • Rules when editing code: (1) new fields must have a default value at declaration / in the constructor; (2) entity constructors other than (owner, faction, centre) must be added to TEMPLATES; (3) only when renaming / moving / changing the meaning of a saved field is a migration needed: add MIGRATIONS[n] (save version n → n+1) in core/SaveCodec.ts and bump SAVE_VERSION. Saves in a format newer than the game are rejected.
  • Pause menu (Esc): Continue, Quit game, Save game, music volume. No Load here.
  • Load game is on the faction picker screen. After choosing a file, the LOAD GAME modal appears before the map is built, with Start / Main menu buttons.
  • .json file (core/SaveCodec.ts, SAVE_FORMAT = 'black-area-save', SAVE_VERSION = 2; v1 saves from before 1.9.0 have their coordinates automatically converted to the new map via longitude / latitude); the map is not saved but rebuilt from MAP_SEED.
  • Old save compatibility: each entity is created fresh by its constructor (new fields get defaults) then the saved fields are layered on top; removed troop types (e.g. helicopters) are skipped; the shop catalog (RULE_FIELDS: options) always comes from current code so new buildings / troops can be bought normally; orders for removed items are cancelled and refunded (Game.dropRemovedOrders). Saves with a version newer than the game are rejected.

10. Victory / defeat & AI

  • A faction is eliminated when it has no capital and no armed soldiers/vehicles left. The player loses when eliminated; wins when every other faction is eliminated.
